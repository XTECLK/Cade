What is Cade

From any message to shipped, without leaving Slack.

Cade turns any message, in a client's channel, a DM or your own dev channel, into a task or an incident in your dev channel, and follows each one through PRs, review, testing and client approval, keeping every thread and its notes for good.

Why Cade

Work stays where your team already is, and stays simple on purpose.

Requests get lost between chats, trackers and inboxes. Cade keeps one thread per task, with no new tool to learn.

Nobody leaves Slack

Clients, developers and QA all work in threads they already read. No new tool to log in to.

Clear ownership

The team owns its tasks. The client approves only what they're asked to, and incidents stay urgent.

Cade only asks

Suggestions are private and change nothing until someone clicks. Deletes ask twice.

One source of truth

Task cards and summaries are rendered from the same record, so they never disagree.

How it works

One thread per task, from first message to done.

Features

Everything a project needs, in the channels you already use.

From anywhere

  • New task, New incident or Move to existing on any message, in any channel or DM
  • Pick the project; the message is copied into the task's thread
  • Works even where not everyone can see the original

Dev channel

  • Tasks with owners, reviewers and testers, for any kind of work
  • Statuses: To do, In progress, In review, In testing, Client review, Done
  • Live status card (optionally pinned until done), with a ⋯ menu to edit or archive

Talk naturally

Write "@mia can you review this" or paste a PR link in a task's thread. The proactive agent offers, privately, to assign or link it, optionally with AI, and changes nothing without a click.

Incidents

/cade incident posts an urgent incident and tracks it in the dev channel immediately, marked as an incident. No triage step.

Partial releases & client review

Send finished PRs to the client before the whole task is done. Whoever you pick approves or pushes back in the task's thread.

Tidy channels

Stray messages are moved into the right thread with a link back, and marked 📤 so everyone can skip them.

Standup

/cade standup walks the team's open tasks one owner at a time. Update statuses and assign as you go.

History that lasts

Every reply in a task's thread is kept in Cade's database, with a page for the thread and one for notes, long after Slack's 90-day limit.

Every feature

Say exactly what to do. Cade does it.

/cade … at the top of a channel, @Cade … in any thread, the ⋯ menu on task cards, message shortcuts and emoji. Commands always work, whatever else is switched on.

Connect with your existing agent

Bring your own agent.

Press Settings → AI agent on Cade's Home tab for an API key, and add Cade to Claude Code, Gemini CLI, Cursor or any client that takes a remote MCP server. The agent reads what you can read and changes tasks as you, after you approve.

claude mcp add --transport http cade https://YOUR-CADE-WORKER/mcp --header "x-apikey: YOUR_API_KEY"

Give it a try

Why wait? Up and running in minutes, with a guided script.

One command walks you through it: it asks for what it needs, runs each step, skips what's already done and tells you when something needs a click in your browser. No AI agent needed. Your tokens never leave your terminal.

  1. 1

    Copy the deploy template

    Use the cade-deploy template on GitHub and clone your copy.

  2. 2

    Run the script

    npm run setup starts the guided setup in your terminal.

  3. 3

    Answer its questions

    Click through the logins and Slack settings when it asks. That's it.
