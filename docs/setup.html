Set up

Set up Cade in minutes. One command guides you.

You get one Cloudflare Worker, one Slack app and, if you like, a Google Sheet. There's no server to run. One command, npm run setup, does the setup with you: it runs each step, checks it worked, and stops whenever it needs you to click something.

  1. 1

    Copy Cade to your own repo

    On Cade's GitHub page, click Fork, or Use this template for a copy without its history. Your copy is what you deploy, and where you pull updates into later. Then clone it:

    git clone https://github.com/<you>/<your copy>.git cade
cd cade
npm install
  2. 2

    Run the setup

    In your cade folder run:

    npm run setup

    It skips what's already done, so if you stop, run it again to carry on.

  3. 3

    Follow along

    Each step says what it's doing. It stops and tells you exactly what to do when a step needs a person:

    • Logging in to Cloudflare, and to Google for the Sheet, in your browser
    • Making a Slack app configuration token, and installing the app
    • Setting up your first group with npm run group: its name and time zone, then its dev channel, existing or new (Cade makes new ones itself)
  4. 4

    Try it

    Send /cade task in your dev channel to track a task, or, on any message anywhere, choose ⋯ → More actions → New task. Send /cade help for the short list, or see the demo and every command.

What you need

  • Node.js 20 or newer, and git
  • A Cloudflare account (the free plan is enough)
  • A Slack workspace where you can create apps
  • Optional: a Google account, for the Sheet

Your tokens stay with you

The commands that need a token or secret ask for it themselves, hidden, in your own terminal. None is ever written to a file or a commit.

What the setup does

Nine steps, most of them done for you

Steps marked You need a click in your browser; the setup waits for you.

  1. Get the code and run the tests
  2. Log in to CloudflareYou
  3. Name and deploy the Worker
  4. Get a Slack app configuration tokenYou
  5. Create the Slack app
  6. Install the app and store its tokenYou
  7. Set up the channels
  8. Optional: the Google Sheet
  9. Check it works

Prefer to do it yourself? The same steps, with what to expect and what to do if one fails, are in GETTING_STARTED.md.
